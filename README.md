# MyBlocklist

This is custom selected domain blocklist generated by [Pihole](https://pi-hole.net/) to use in [Openwrt](https://openwrt.org/) router.

To populate `FTL_URL.txt` we can run `Populate_FTL.sh` but make sure to check and set `DB_FILE` to `pihole-FTL.db` path.

Also `Ignore.txt` will ignore exact domains from adding them to blocklists and `IgnoreRegex.txt` to ignore matching domains by regular expression patterns.

Github Action is set to trigger on `Commit FTL_URL.txt`

This runs `update_blocklist.sh` and it appends new entries to `CustomBlocklist1.txt` and `CustomBlocklist2.txt`

Both files have same entries but different entry order.
